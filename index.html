Your agent. Your box.

A personal AI agent you run, with a chat app that follows you to the car.

One Cloudflare Worker (or the same thing on a box at home) holds the door, the settings, and a chat room per agent. One container image holds the harness: a Go process with a persona, a memory you can sqlite3, and the tools you granted. The harness dials out. No open ports. Ever.

Sign in with Google. An admin keeps a short list of who may enter and which agents they may talk to. Talk from a browser, from the Android app, or from the iPhone app — same room, same thread, same agent, and a message card on the dash when you are driving.

harness
The agent runtime. Static Go binary, one persona, any OpenAI-compatible model, MCP plugins compiled in. It remembers on Thursday.
agent
One named person on that harness: its own room, its own memory, its own keys and grants. Kit is not Ada.
settings
The admin screens. Users, agents, grants, keys, spend. Never a hop in a chat turn.
chat
The PWA and the Durable Object room behind it. Phones dial in; the harness dials in; the Worker never dials the house.

The difference

A harness is a process. A marketplace is a costume.

What this is

  • A binary you run. Aims, voice, and work still exist next week.
  • The model is a socket — Gemini, OpenAI, Grok, Ollama. Swap it. The loop stays.
  • A tool listed in mcp.toml is the grant. Nothing else is reachable.
  • Outbound chat only. Browser, Android, iPhone share one room. No open ports. Ever.
  • Independent lookups fan out in one round; the next round uses the results.

What it is not

  • A plugin marketplace with “harness” in the README.
  • Prompts and sub-agents that live in someone else's context window.
  • A chatbot that dies when the window gets expensive.
  • A gateway in the token path so every message pays a platform tax.
  • A hosted service. You hold the keys; we hold the code.

Connecting accounts

Gmail, Calendar, Strava, Garmin — a laptop hop, then paste.

The harness is headless. To connect an account, the agent gives you a link; the provider sends you back to a static page that shows a one-time code and stores nothing. Paste it to the agent: /auth google <code>. The refresh token never leaves the agent's box. What that means for your data: privacy.
