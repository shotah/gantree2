## 0. Decide

- [x] **D — Cloud target: (a) Cloudflare Workers + Containers; celld
      at home.** Decided 2026-10-10. Cloudflare acquired Deno on
      2026-10-09 and is merging celld into workerd (Dahl and Belder
      leading), so the two implementations converge into one platform
      run by one vendor. Betting on the Workers manifest is betting on
      where celld is going. `deploy-cloudflare.yml` stays; no
      `deploy-vm.yml`. Watch: celld's repo may move or be renamed
      during the merge — `npm run deploy:home` and
      [install.md](install.md#home-celld) must track it. Deno Deploy
      and the standalone Deno runtime are not in our stack; nothing to
      migrate.
- [x] **D — Apps repo: one `gantree2-apps`.** Decided 2026-10-10.
      `cab/` (Android) and `helm/` (iOS) copied in side by side, one
      CI matrix, shared `shared/theme/` generated by gantree's
      `npm run theme:export`. Backlog lives there:
      `../gantree2-apps/docs/todo.md`.
- [x] **D — Wire renames: yes.** Decided 2026-10-10. `PENDANT_*` →
      `CHAT_*`, `CHANNEL=pendant` → `CHANNEL=chat`, `cranes` →
      `agents`, `pendant:<slug>:<sub>` → `chat:<slug>:<sub>`, plugin
      `pendant` → `chat`. Nothing new is written with the old names;
      aliases (`cranes` beside `agents` in `/api/auth/me`, `CHANNEL=
      pendant` accepted) live only until the cutover walk in §9.
- [x] **D — Entry (2026-10-10).** No splash inside the Worker — the
      public splash is the Pages site. `/` is a router, not a page
      (`lib/door/landing.ts`): no session → `/login`; admin or operator
      → `/agents`; member with one agent → `/chat/<slug>`; member with
      several or none → `/chat` (picker). Chat and management are two
      surfaces with one link each way: the chat gear menu grows
      **Manage <slug>** / **All agents** for admin and operator-of;
      every agent card and dashboard has **Open chat**. PWA `start_url`
      stays `/`. No "config mode" toggle on the chat page — on a phone
      the switch is a page, not a mode.
- [x] **D — Plugins not carried (2026-10-10):** `youtube`, `boards`
      (agents posting to each other never panned out), `cast` /
      mcp-beam (LAN only), `search` / gemini-google-search (Gemini
      calling Gemini; `web_search` is a harness builtin).
      `gantry-fleet` is a dead repo, never a plugin. `twitter` carried
      but **unproven** — first to go if it costs anything.
- [x] **D — Hosted: yes (2026-10-10).** v1 said "no SaaS, one
      household per deploy"; the owner was on the fence and v1 was not
      durable enough to sell anyway. v2 is: Workers + Containers with
      celld converging on workerd, one code path for home and cloud,
      snapshots in R2. So gantree is sold three ways — free self-host,
      paid setup time, and a hosted door where every key is the
      customer's. What stays out: reselling tokens, a shared tools
      client, orgs beyond one household per account. Plan in
      [todo.md](todo.md#hosted-phase-5--the-paid-door); numbers in
      [monetize.md](monetize.md).
- [x] **D — License: MIT (2026-10-10).** Root `LICENSE`, copyright
      `shotah` like the plugins; `package.json` `"license": "MIT"`. The
      code stays open; the money is hosting and time
      ([monetize.md](monetize.md)). Every plugin under `harness/mcp/`
      already carried its own MIT file.
- [x] **D — The mark (2026-10-10).** A bare tree with roots — the
      owner's traced silhouette, **`assets/tree.svg`** (one black path,
      SVG 1.0, 1264×1280 pt) — recoloured to the theme foreground and
      scaled into the 64-box, with a hairline string and a small

      an apple; the accent made it an orange and the owner kept it).
      The tree is the harness, the bough is the hoist, the orange is

      rasterises everything else. Palette from `lib/theme/catalog.ts`.
      Monochrome variant (`currentColor`) for favicons and the Paper
      theme. Wordmark `gantree` lowercase beside it on the banner only.
